Dcon Mix 사용자 매뉴얼

버전 1.0.1

Dcon Mix는 ProPresenter에서 보내는 MIDI 신호를 받아서 DM3, Qu-5/6/7, SQ-5/6/7 믹서를 제어하는 macOS 애플리케이션입니다.

시작하기

시스템 요구사항

  • 운영체제: macOS 10.9 이상
  • Python: 3.7 이상 (소스 코드 실행 시)
  • 필수 패키지: mido, pythonosc, rtmidi
  • 네트워크: 믹서와 같은 네트워크에 연결되어 있어야 함

설치 방법

방법 1: DMG 파일로 설치 (권장)

  1. Dcon-Mix-1.0.1.dmg 파일을 다운로드합니다.

  2. DMG 파일을 더블클릭하여 마운트합니다.

  3. Applications 폴더로 앱을 드래그합니다.

  4. Applications 폴더에서 앱을 실행합니다.

  5. “앱이 손상되었습니다” 경고가 나타나면:

    xattr -cr "/Applications/Dcon Mix.app"

    터미널에서 위 명령을 실행하세요.

방법 2: 소스 코드에서 실행

  1. 프로젝트를 클론하거나 다운로드합니다.

  2. 의존성 패키지를 설치합니다:

    pip install -r requirements.txt

  3. 앱을 실행합니다:

    python app.py

첫 실행

  1. 앱을 실행하면 “MIDI 믹서 설정” 창이 열립니다.
  2. 앱이 자동으로 가상 MIDI 포트를 생성합니다.
    • 포트 이름: “Dcon Mix In” (ProPresenter에서 선택할 포트)
  3. 로그 영역에서 가상 포트 생성 상태를 확인할 수 있습니다.

기본 사용법

앱 인터페이스 설명

앱 창은 다음과 같은 섹션으로 구성되어 있습니다:

1. 믹서 선택

  • 드롭다운 메뉴에서 사용할 믹서를 선택합니다.
  • 지원되는 믹서:
    • DM3: OSC 통신 사용
    • Qu-5/6/7: TCP/IP MIDI 또는 USB MIDI 사용
    • SQ-5/6/7: TCP/IP MIDI 또는 USB MIDI 사용

2. 믹서 연결 설정

선택한 믹서에 따라 다른 설정 항목이 표시됩니다.

DM3 설정: - DM3 IP: DM3 믹서의 IP 주소 (기본값: 192.168.4.2) - 포트: OSC 포트 번호 (기본값: 49900)

Qu-5/6/7 설정: - IP Address: Qu 믹서의 IP 주소 (기본값: 192.168.5.10) - 포트: TCP/IP MIDI 포트 (기본값: 51325)

SQ-5/6/7 설정: - IP Address: SQ 믹서의 IP 주소 (기본값: 192.168.5.10) - 포트: TCP/IP MIDI 포트 (기본값: 51325)

3. MIDI 채널 설정

  • 믹서 MIDI 채널: 믹서로 전송되는 MIDI 메시지의 채널 (1-16)
  • DM3는 OSC를 사용하므로 이 설정이 비활성화됩니다.
  • Qu-5/6/7와 SQ-5/6/7만 사용합니다.

4. 연결 버튼

  • “믹서 연결” 버튼을 클릭하여 믹서에 연결합니다.
  • 연결 성공 시 버튼이 “연결 해제”로 변경됩니다.
  • 연결 중에는 설정을 변경할 수 없습니다.

5. 로그 영역

  • 모든 작업과 MIDI 메시지가 실시간으로 표시됩니다.
  • 연결 상태, MIDI 수신, 오류 메시지 등을 확인할 수 있습니다.

믹서 연결하기

  1. 믹서 선택: 드롭다운에서 사용할 믹서를 선택합니다.
  2. 연결 설정 입력:
    • DM3: IP 주소와 포트를 입력합니다.
    • Qu-5/6/7 또는 SQ-5/6/7: IP 주소, 포트, MIDI 채널을 입력합니다.
  3. “믹서 연결” 버튼 클릭:
    • 앱이 네트워크 연결을 테스트합니다 (ping).
    • 연결 성공 시 로그에 “🎉 [믹서명] 믹서 연결 성공” 메시지가 표시됩니다.
    • 연결 실패 시 오류 메시지가 표시됩니다.
  4. 연결 확인: 로그 영역에서 연결 상태를 확인합니다.

설정 저장 및 불러오기

  • 앱은 연결 성공 시 자동으로 현재 설정을 저장합니다.
  • 저장 위치: ~/.midi_mixer_control/prefs.json
  • 다음 실행 시 마지막 설정이 자동으로 복원됩니다.

기능 상세 설명

소프트키 제어 (Soft Key Control) - Qu-5/6/7, SQ-5/6/7만

ProPresenter에서 소프트키를 트리거할 수 있습니다.

ProPresenter 설정

  • MIDI 채널: 0
  • 메시지 타입: Note On / Note Off
  • Note 번호: 소프트키 번호 (0-7)
    • 소프트키 1 → Note 0
    • 소프트키 2 → Note 1
    • … (최대 소프트키 8까지)

동작 방식

  • Note On (velocity > 0)과 Note Off를 순차적으로 전송합니다.
  • 실제 MIDI Note 번호는 0x30 + 소프트키 번호로 변환됩니다.

참고: DM3는 소프트키 기능을 지원하지 않습니다.

씬 리콜 (Scene Recall)

ProPresenter에서 씬을 호출하면 믹서의 해당 씬이 자동으로 불러와집니다.

ProPresenter 설정

  • MIDI 채널: 1 (채널 0이 아님)
  • 메시지 타입: Note On
  • Note 번호: 씬 번호 - 1
    • 씬 1 → Note 0
    • 씬 2 → Note 1
    • 씬 3 → Note 2
    • … (최대 씬 100까지)

믹서별 동작

DM3: - OSC 메시지로 씬을 호출합니다. - 씬 번호는 1-100 범위입니다.

Qu-5/6/7: - Program Change 메시지로 씬을 호출합니다. - Program = (씬 번호 - 1) - 씬 번호는 1-100 범위입니다.

SQ-5/6/7: - Program Change 메시지로 씬을 호출합니다. - Program = (씬 번호 - 1) - 씬 번호는 1-100 범위입니다.

뮤트 제어 (Mute Control)

ProPresenter에서 MIDI 신호를 보내면 믹서의 입력 채널을 뮤트/언뮤트할 수 있습니다.

ProPresenter 설정

  • MIDI 채널: 2 (채널 0이 아님)
  • 메시지 타입: Note On / Note Off
  • Note 번호: 채널 번호 - 1
    • 채널 1 → Note 0
    • 채널 2 → Note 1
    • 채널 3 → Note 2
    • … (최대 채널 16까지)
  • Velocity:
    • ≥ 1: 뮤트 On
    • 0 또는 Note Off: 뮤트 Off

믹서별 동작

DM3: - OSC 메시지로 채널 뮤트를 제어합니다. - 채널 번호는 1-16 범위입니다.

Qu-5/6/7: - NRPN 시퀀스로 채널 뮤트를 제어합니다. - 4개의 Control Change 메시지를 순차적으로 전송합니다: 1. CC 99 = 0 (NRPN MSB) 2. CC 98 = (채널 번호 - 1) (채널 번호, 0-based) 3. CC 6 = 0 (Data Entry MSB) 4. CC 38 = 뮤트 값 (1=mute, 0=unmute)

SQ-5/6/7: - Qu-5/6/7와 동일한 NRPN 시퀀스를 사용합니다.

ProPresenter 연동

1. ProPresenter에서 MIDI 출력 설정

  1. ProPresenter를 실행합니다.
  2. 설정(Settings) → 기기(Device) 메뉴로 이동합니다.
  3. 기기(Device) 섹션에서:
    • 왼쪽 하단의 “+”버튼을 눌러 MIDI 장치 생성
    • 출력 포트: “Dcon Mix In” 선택
    • 포트가 보이지 않으면 Dcon Mix 앱이 실행 중인지 확인하세요.

2. 소프트키 설정 (Qu-5/6/7, SQ-5/6/7만)

  1. ProPresenter에서 슬라이드나 액션을 선택합니다.
  2. “MIDI” 탭으로 이동합니다.
  3. “MIDI 메시지 전송” 옵션을 활성화합니다.
  4. 설정:
    • 채널: 0
    • 타입: Note On / Note Off
    • Note: 소프트키 번호 (0-7)
      • 예: 소프트키 1 → Note 0, 소프트키 2 → Note 1
    • Velocity: 127 (Note On) 또는 0 (Note Off)

참고: DM3는 소프트키 기능을 지원하지 않습니다.

3. 씬 리콜 설정

  1. ProPresenter에서 씬을 선택합니다.
  2. 씬 설정에서 “MIDI” 탭으로 이동합니다.
  3. “MIDI 메시지 전송” 옵션을 활성화합니다.
  4. 설정:
    • 채널: 1
    • 타입: Note On
    • Note: (씬 번호 - 1)
      • 예: 씬 1 → Note 0, 씬 2 → Note 1

4. 뮤트 제어 설정

  1. ProPresenter에서 슬라이드나 액션을 선택합니다.
  2. “MIDI” 탭으로 이동합니다.
  3. “MIDI 메시지 전송” 옵션을 활성화합니다.
  4. 설정:
    • 채널: 2
    • 타입: Note On (뮤트) 또는 Note Off (언뮤트)
    • Note: (채널 번호 - 1)
      • 예: 채널 1 → Note 0, 채널 2 → Note 1
    • Velocity: 127 (뮤트 On) 또는 0 (뮤트 Off)

5. 테스트

  1. Dcon Mix 앱에서 믹서에 연결합니다.
  2. ProPresenter에서 테스트 씬이나 액션을 실행합니다.
  3. Dcon Mix의 로그 영역에서 MIDI 메시지 수신을 확인합니다.
  4. 믹서에서 씬이 변경되거나 채널이 뮤트되는지 확인합니다.

고급 설정

MIDI 채널 설정

Qu-5/6/7와 SQ-5/6/7 믹서의 경우, 믹서로 전송되는 MIDI 메시지의 채널을 설정할 수 있습니다.

  • 기본값: 1
  • 범위: 1-16
  • 설정 위치: “MIDI 채널 설정” 섹션의 “믹서 MIDI 채널” 스핀박스

참고: DM3는 OSC를 사용하므로 MIDI 채널 설정이 필요 없습니다.

네트워크 설정

DM3 네트워크 설정

  • 기본 IP: 192.168.4.2
  • 기본 포트: 49900
  • DM3 믹서의 네트워크 설정과 일치해야 합니다.

Qu-5/6/7 네트워크 설정

  • 기본 IP: 192.168.5.10
  • 기본 포트: 51325
  • Qu 믹서의 네트워크 설정과 일치해야 합니다.

SQ-5/6/7 네트워크 설정

  • 기본 IP: 192.168.5.10
  • 기본 포트: 51325
  • SQ 믹서의 네트워크 설정과 일치해야 합니다.

로그 확인

로그 영역에서 다음 정보를 확인할 수 있습니다:

  • 연결 상태: 믹서 연결 성공/실패 메시지
  • MIDI 수신: ProPresenter에서 받은 MIDI 메시지
  • 믹서 제어: 씬 리콜, 뮤트 제어 등의 동작 로그
  • 오류 메시지: 연결 실패, 전송 실패 등의 오류

로그는 실시간으로 업데이트되며, 스크롤하여 이전 메시지를 확인할 수 있습니다.

설정 파일 위치

앱의 설정은 다음 위치에 저장됩니다:

~/.midi_mixer_control/prefs.json

이 파일을 직접 편집하여 설정을 변경할 수 있습니다. 파일 형식은 JSON입니다.

문제 해결

자주 묻는 질문 (FAQ)

Q1: 가상 MIDI 포트가 보이지 않아요.

해결 방법: 1. Dcon Mix 앱이 실행 중인지 확인하세요. 2. 앱을 재시작해보세요. 3. 터미널에서 다음 명령으로 rtmidi가 제대로 설치되었는지 확인: bash python -c "import rtmidi; print('rtmidi OK')"

Q2: 믹서 연결이 실패해요.

해결 방법: 1. 네트워크 연결 확인: - 컴퓨터와 믹서가 같은 네트워크에 연결되어 있는지 확인 - 터미널에서 ping 테스트: bash ping [믹서 IP 주소] 2. IP 주소 확인: - 믹서의 실제 IP 주소가 설정과 일치하는지 확인 - 믹서의 네트워크 설정 메뉴에서 IP 주소 확인 3. 포트 확인: - DM3: OSC 포트가 49900인지 확인 - Qu-5/6/7, SQ-5/6/7: TCP/IP MIDI 포트가 51325인지 확인 4. 방화벽 확인: - macOS 방화벽이 연결을 차단하지 않는지 확인

Q3: ProPresenter에서 MIDI 메시지를 보냈는데 믹서가 반응하지 않아요.

해결 방법: 1. MIDI 포트 확인: - ProPresenter에서 “Dcon Mix In” 포트가 선택되어 있는지 확인 2. MIDI 채널 확인: - 소프트키: 채널 0 사용 (Qu-5/6/7, SQ-5/6/7만) - 씬 리콜: 채널 1 사용 - 뮤트 제어: 채널 2 사용 3. Note 번호 확인: - 소프트키: Note = 소프트키 번호 (0-7) - 씬 리콜: Note = (씬 번호 - 1) - 뮤트 제어: Note = (채널 번호 - 1) 4. 로그 확인: - Dcon Mix의 로그 영역에서 MIDI 메시지 수신 여부 확인 - “🎵 MIDI 수신: …” 메시지가 보이는지 확인

Q4: 앱이 갑자기 종료되거나 응답하지 않아요.

해결 방법: 1. 앱을 완전히 종료하고 다시 실행해보세요. 2. 터미널에서 실행하여 오류 메시지를 확인: bash python app.py 3. 로그 파일이 있다면 확인해보세요.

Q5: 설정이 저장되지 않아요.

해결 방법: 1. 설정 파일 위치 확인: bash ls -la ~/.midi_mixer_control/prefs.json 2. 파일 권한 확인: bash chmod 644 ~/.midi_mixer_control/prefs.json 3. 설정 파일을 삭제하고 다시 저장: bash rm ~/.midi_mixer_control/prefs.json 앱을 재시작하고 설정을 다시 입력한 후 연결해보세요.

일반적인 오류 메시지

“Ping 테스트 실패”

  • 원인: 네트워크 연결 문제 또는 잘못된 IP 주소
  • 해결: IP 주소를 확인하고 네트워크 연결을 확인하세요.

“TCP 포트 연결 실패”

  • 원인: 포트 번호가 잘못되었거나 방화벽이 차단
  • 해결: 포트 번호를 확인하고 방화벽 설정을 확인하세요.

“DM3 OSC 전송 실패”

  • 원인: DM3와의 연결이 끊어짐
  • 해결: 연결을 해제하고 다시 연결해보세요.

“Qu-5/6/7 MIDI 전송 실패” 또는 “SQ-5/6/7 MIDI 전송 실패”

  • 원인: TCP/IP 연결이 끊어짐
  • 해결: 연결을 해제하고 다시 연결해보세요.

부록

MIDI 신호 매핑표

ProPresenter → Dcon Mix (가상 MIDI 포트)

기능 MIDI 채널 메시지 타입 Note 번호 Velocity 설명
소프트키 0 Note On/Off 0-7 127/0 Qu-5/6/7, SQ-5/6/7만
씬 리콜 1 Note On 0-99 > 0 Note = (씬 번호 - 1)
뮤트 On 2 Note On 0-15 ≥ 1 Note = (채널 번호 - 1)
뮤트 Off 2 Note Off 또는 Note On 0-15 0 Note = (채널 번호 - 1)

Dcon Mix → 믹서

DM3 (OSC): - 소프트키: 지원하지 않음 - 씬 리콜: /yosc:req/ssrecall_ex "scene_a" <index> - 뮤트 On: /yosc:req/set/MIXER:Current/InCh/Fader/On/<channel>/1 0 - 뮤트 Off: /yosc:req/set/MIXER:Current/InCh/Fader/On/<channel>/1 1

Qu-5/6/7 (MIDI): - 소프트키: Note On/Off (note = 0x30 + 소프트키 번호) - 씬 리콜: Program Change (program = 씬 번호 - 1) - 뮤트: NRPN 시퀀스 (CC 99→CC 98→CC 6→CC 38)

SQ-5/6/7 (MIDI): - Qu-5/6/7와 동일

제한사항

  • 씬 번호: 1-100 (Note 0-99)
  • 채널 번호: 1-16 (Note 0-15)
  • 소프트키: 1-8 (Note 0-7, Qu-5/6/7, SQ-5/6/7만)
  • MIDI 채널: 1-16

가상 MIDI 포트

  • 포트 이름: “Dcon Mix”
  • 입력 포트: “Dcon Mix In” (ProPresenter에서 선택)
